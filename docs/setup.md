# Setup Guide

## 1. Import the workflow

Import:

```text
workflow/python-from-zero-student-registration.json
```

into n8n.

The JSON is a sanitized public template. It does not contain the original production credentials or private infrastructure values.

## 2. Configure Google Sheets

Create a Google Sheet with the following headers:

```text
REGISTRATION DATE
FULL NAME
EMAIL
WHATSAPP NUMBER
LOCATION
PROGRAMMING EXPERIENCE
DEVICE AVAILABLE
WHY DO YOU WANT TO JOIN
```

Connect your Google Sheets OAuth credential to:

- `Lookup Existing Registration`
- `Save to Google Sheets`

Select your own spreadsheet and worksheet.

## 3. Configure Gmail

Connect your Gmail OAuth credential to:

```text
Send Confirmation Email
```

The workflow sends the confirmation to the email submitted by the registrant.

Review the sender name and email content before activating the workflow.

## 4. Configure the WhatsApp destination

Replace:

```text
https://chat.whatsapp.com/YOUR_WHATSAPP_INVITE
```

with your actual WhatsApp group/community invite link.

Do not commit a private production invite link to a public repository.

## 5. Configure the validation error page

The validation-error page contains a link back to the registration form.

Replace:

```text
https://YOUR_N8N_HOST/form/python-from-zero
```

with the actual URL generated by your n8n instance.

If you rename the form path, update this URL as well.

## 6. Review the form

The original form contains:

- Full Name
- Email
- WhatsApp Number
- Location
- Programming Experience
- Device Available
- Why do you want to join?

Modify the fields to match your program.

## 7. Review validation

The JavaScript validation checks:

### Email

A basic email format:

```text
name@example.com
```

### Phone

The validation accepts:

- International numbers beginning with `+`
- Local numbers beginning with `0`

Spaces and hyphens are removed before validation.

For a production system serving multiple countries, consider replacing this basic validation with a proper phone-number parsing/normalization library or service.

## 8. Test the duplicate-registration branch

Submit a test registration.

Then submit another registration using the same email.

The second submission should go through:

```text
Lookup Existing Registration
        ↓
Already Registered?
        ↓
Show Already Registered
```

## 9. Test the successful branch

Submit a new email.

The expected path is:

```text
Save to Google Sheets
        ↓
Send Confirmation Email
        ↓
Show WhatsApp Group
```

Verify that:

- The row appears in Google Sheets.
- The confirmation email arrives.
- The WhatsApp link works.
- The final page renders correctly.

## 10. Activate

Only activate the workflow after completing the tests.

For production, also monitor failed executions and periodically review the registration sheet.
